## 1. 배경과 목적

미션 제출본(**v1.0**)은 코디세이 네이토 사전평가를 전 항목 통과했다. 이 문서군은 그 결과물을 **채용 포트폴리오 수준**으로 끌어올리기 위해 필요한 작업을 스펙으로 정의한다.

### 서사 전환

| | v1.0 (제출본) | 포트폴리오 목표 |
|---|---|---|
| 한 줄 정의 | 시계열 데이터를 아는 AI 비서 | **대전 상권 대시보드를 보면서 AI와 대화하며 상권을 분석하는 도구** |
| 사용자 행동 | 숫자 몇 개 입력 → 질문 | 지도·차트에서 지역·업종·기간을 고르고 → 그 화면에 대해 질문 |
| 차별점 | 컨텍스트 주입(요약) | 컨텍스트 주입(요약 + 사전 분석 리포트 + **지금 보고 있는 화면 상태**) |

이미 합의된 3단계 계획(1: 현재 제출본 / 2: 중앙 대시보드 임베드 + 우측 채팅 / 3: 대시보드 필터 상태를 채팅 프롬프트에 주입)을 **실행 가능한 스펙 항목**으로 분해하고, 포트폴리오에서 실무 감각을 보여줄 신뢰성·문서 항목을 더한다.

## 3. 목표와 성공 기준

| ID | 목표 | 측정 |
|---|---|---|
| **G1** | 리뷰어가 라이브 URL에서 **3분 안에** "대시보드에서 지역·업종을 고르고 AI에게 그 화면을 물어보는" 경험을 한다 | 데모 시나리오 문서 + 실제 동작 |
| **G2** | 코드에서 실무 감각이 드러난다 (테스트·CI·관측성·비용 방어) | CI 초록, 핵심 경로 테스트 존재, 로그에 요청 ID·토큰 비용 |
| **G3** | 문서만 읽어도 아키텍처와 주요 의사결정을 이해할 수 있다 | 아키텍처 구성도 + ADR 3건 이상 |
| **G4** | 성능·접근성이 일정 수준 이상 | Lighthouse 성능·접근성 각 90+ |

## 4. 비범위 (Non-goals)

- **대시보드 자체를 프레임워크로 재구현** — 분석 저장소 산출물을 그대로 임베드한다. *(결정 ①)*
- **인증·멀티유저 전체 (D 그룹)** — 서사를 "개인 상권 분석 도구"로 확정. D1·D2 제외. *(결정 ②)*
- **커스텀 도메인** — Vercel/Render 기본 URL 유지. *(결정 ④)*
- 실시간 협업, 결제, 네이티브 모바일 앱.
- 미션 채점 기준을 넘어서는 "제품화" (SLA, 온콜 등).
- **임베드 대시보드의 팔레트 통일** — 분석 저장소 수정이 필요하므로 범위 밖. 다크 패널은 "데이터 뷰포트"로 액자화한다([`design/design-system.md`](design/design-system.md)).

> 결정 번호의 근거는 [`decisions.md`](decisions.md) 참조.
