## 토큰·비용 (구현됨, 2026-09-09)

| | 값 | 이유 |
|---|---|---|
| `CHAT_MAX_TOKENS` | 900 | 500에서는 지표를 여럿 묻는 질문이 문장 중간에 끊겼다(실측). 900에서 같은 질문의 답이 470토큰으로 완결됐다 — 상한은 잘림만 없애고 답변을 늘리지 않는다 |
| `REPORT_MAX_TOKENS` | 1200 | 4블록 구조를 채워야 한다. [한계] 블록이 잘리면 안 된다 |
| `HISTORY_MAX_MESSAGES` | 8 | 이력을 매 요청 통째로 다시 올린다. 상한이 없으면 입력이 대화 길이에 비례해 늘어난다 |
| `SUMMARY_CACHE_TTL` | 30초 | 요약은 채팅 한 번마다 컬렉션을 통째로 읽었다. 계산이 아니라 **읽기**가 비싸다. 쓰기 경로(생성·수정·삭제)가 캐시를 직접 비우므로 화면이 어긋나지 않는다 — TTL은 다중 인스턴스 대비 안전망 |
| 프롬프트 블록 순서 | 고정 → 가변 | OpenAI 자동 캐싱은 **앞에서부터 같은 구간**만 1,024토큰 이상일 때 재사용한다. 고정 프리픽스 2,432자(전체의 95%), 실측 `cached_tokens=1024` |

**셋 다 환경변수로 덮을 수 있다.** 배포에서 값만 바꿔 대응한다.

주의: 가변 블록(요약·주제·페르소나)이 하나라도 앞으로 올라가면 그 뒤 전체가
캐시에서 빠지는데 **응답은 멀쩡해서 아무도 모른다.** `backend/tests/test_chat.py`가
프리픽스 길이를 검사한다.

## 로깅 (C4, 구현됨 2026-09-09)

무료 티어 Render의 로그는 텍스트 스트림 하나다. 한 요청을 되짚으려면 줄마다 같은
식별자가 있어야 하고, 기계로 걸러야 하니 JSON이어야 한다. 표준 `logging`·`json`만
쓴다 — 의존성을 늘리지 않았다.

| | |
|---|---|
| 요청 ID | `X-Request-Id` 헤더로 받고, 없으면 만든다. **응답 헤더로도 돌려준다** — 이상한 답을 본 사람이 그 값을 가져오면 로그에서 바로 찾는다 |
| 요청 로그 | `method` `path` `status` `ms`. **`GET /`는 제외** — 10분마다 들어오는 콜드스타트 핑으로 로그가 채워지면 아무것도 못 찾는다 |
| 채팅 로그 | `model` `prompt_tokens` `cached_tokens` `completion_tokens` `usd` `truncated` `topic` `persona` `history_messages` |
| 배포본 | `GET /`가 `build`(커밋 SHA 12자)를 돌려준다. Render의 `RENDER_GIT_COMMIT`을 쓴다 |

**`cached_tokens`가 0으로 굳으면 프롬프트 캐시 프리픽스가 깨진 것이다.** 응답은
멀쩡하고 비용만 조용히 두 배가 되므로 이 로그가 유일한 단서다.

**`truncated`는 답변이 상한에 걸렸다는 뜻이다.** 화면에서는 "문장이 좀 어색한" 것으로만
보인다 — 실제로 `CHAT_MAX_TOKENS=500`일 때 그렇게 잘리고 있었고 아무도 몰랐다.

비용 단가는 `observability.PRICE_PER_1M`에 있다. **모델을 바꾸면 여기도 바꿔야 한다** —
안 바꾸면 로그의 비용이 조용히 틀린다. 그래서 모델 이름을 함께 남긴다.

## 남용 방어와 에러 트래킹 (C3·C7, 구현됨 2026-09-09)

포트폴리오 데모라 링크가 어디로 갈지 모른다. 누가 반복해서 두드리면 요금은 그대로 나간다.

| | 기본값 | 무엇을 막나 |
|---|---|---|
| `CHAT_RATE_PER_MINUTE` | 10 | IP 단위 분당 요청. **사람이 손으로 낼 수 있는 속도**를 넘는 것 |
| `DAILY_TOKEN_BUDGET` | 300,000 | 하루 총 토큰. **느리게 오래 두드리는 것** — 분당 제한만으로는 못 막는다 |

둘 다 `0`이면 그 겹이 꺼진다. 채팅에만 건다 — 돈이 나가는 건 거기뿐이고, 요약을
막으면 화면이 그냥 죽는다.

IP는 `X-Forwarded-For`를 먼저 본다. **Render는 프록시 뒤라 `client.host`가 전부 같다** —
안 보면 모든 사용자가 한 양동이를 나눠 쓰게 된다.

토큰은 **사후 기록**이다. 요청 전에는 얼마나 쓸지 알 수 없어 상한을 살짝 넘길 수 있지만,
넘긴 만큼은 이미 응답으로 나간 뒤다.

인메모리다. 인스턴스가 하나라 충분하고 무료 티어에 Redis를 붙일 이유가 없다.
**여러 인스턴스로 늘리면 상한이 인스턴스 수만큼 느슨해진다** — 그때 옮긴다.

### C7 Sentry

`SENTRY_DSN`이 없으면 아예 켜지 않는다. `sentry-sdk`가 설치돼 있지 않아도 앱은 뜬다 —
의존성 하나가 빠졌다고 서비스 전체가 죽으면 안 된다.

`send_default_pii=False` + `before_send` 필터로 **사용자의 질문과 답변이 이벤트에 실리지
않게** 두 겹으로 막는다. 이 서비스가 다루는 건 사람이 어디에 창업할지 묻는 말이다.
