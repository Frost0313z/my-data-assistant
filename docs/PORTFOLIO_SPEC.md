## 1. 배경과 목적

미션 제출본(**v1.0**)은 코디세이 네이토 사전평가를 전 항목 통과했다. 이 문서는 그 결과물을 **채용 포트폴리오 수준**으로 끌어올리기 위해 필요한 작업을 스펙으로 정의한다.

### 서사 전환

| | v1.0 (제출본) | 포트폴리오 목표 |
|---|---|---|
| 한 줄 정의 | 시계열 데이터를 아는 AI 비서 | **대전 상권 대시보드를 보면서 AI와 대화하며 상권을 분석하는 도구** |
| 사용자 행동 | 숫자 몇 개 입력 → 질문 | 지도·차트에서 지역·업종·기간을 고르고 → 그 화면에 대해 질문 |
| 차별점 | 컨텍스트 주입(요약) | 컨텍스트 주입(요약 + 사전 분석 리포트 + **지금 보고 있는 화면 상태**) |

이미 합의된 3단계 계획(1: 현재 제출본 / 2: 중앙 대시보드 임베드 + 우측 채팅 / 3: 대시보드 필터 상태를 채팅 프롬프트에 주입)을 이 문서에서 **실행 가능한 스펙 항목**으로 분해하고, 포트폴리오에서 실무 감각을 보여줄 신뢰성·문서 항목을 더한다.

## 4-1. 벤치마킹 — 서울시 상권분석서비스(골목상권)

조사일 2026-09-08 · https://golmok.seoul.go.kr/commercialArea/commercialArea.do

같은 도메인(상권 데이터 공개 서비스)의 대표 사례. **성격이 다르다는 점이 핵심이다** — 골목상권은 *데이터를 보여주는* 서비스이고, 우리는 *데이터를 설명해주는* 서비스다. 골목상권에서 챗봇은 우상단 아이콘의 보조 도구지만, 우리는 AI가 주역이다. 그래서 베끼는 게 아니라 **골라 쓴다.**

### 골목상권이 잘하는 것

| # | 패턴 | 관찰 |
|---|---|---|
| 1 | **페르소나 기반 진입** | 상단 네비가 `뜨는 상권 / 나는 사장 / 나도 곧 사장`. "무슨 데이터를 볼래?"가 아니라 **"너는 누구냐"**로 나눠 처음 온 사람이 자기 자리를 찾는다 |
| 2 | **질문으로 시작하는 마법사** | "나도 곧 사장" 첫 화면이 **"창업하려는 업종이 있으세요?" → [아니요, 고민중입니다] / [네, 있습니다]**. 이후 업종(외식업·서비스업·소매업) → 지역 순으로 좁혀가고 "처음으로"로 되돌아갈 수 있다 |
| 3 | **강제 온보딩** | 페이지마다 "○○이란?" 모달 + `튜토리얼 시작하기` + `다시 보지 않기`. 서비스 정의를 첫 3초에 전달 |
| 4 | **랭킹이 화면의 중심** | 좌측 `순위 TOP 10` — "1위 송파구 잠실4동 441개 7.8%↑". 지도를 못 읽어도 리스트만 보면 답이 나온다. 지도 마커에도 수치를 직접 얹음 |
| 5 | **기준 시점 상시 노출** | "2026년 2분기 기준 (전분기)"를 랭킹 바로 위에 고정 → 데이터 신뢰성 방어 |
| 6 | **결과를 남긴다** | `분석리포트 비교담기` — 저장명을 붙여 분석을 저장·비교 |
| 7 | 레이어 토글 레일 | 우측 아이콘 7개(상권영역·점포이력·주변정보·유동인구 도로별/건물별·인구밀도·지원센터)로 지도 레이어 on/off |

### 우리가 가져올 것 → 스펙 반영

| 벤치마크 | 우리 방식 | 스펙 |
|---|---|---|
| ① 페르소나 진입 · ② 질문 마법사 | 목적 칩 3개 → **주제 자동 선택 + 질문 자동 전송**. 마법사 단계를 AI가 한 번에 압축하는 것이 우리 차별점 | **A9** |
| ④ TOP 10 랭킹 | 리스트를 직접 렌더하지 않고 **주제별 제안 질문**으로 AI가 답하게 ("교체율 높은 동 TOP 5") | **A10** |
| ③ 온보딩 모달 | 모달로 막지 않고 **AI의 첫 인사말**로 (채팅 서비스에 더 자연스러움) | **A11** |
| ⑤ 기준 시점 | 하단 각주 → **주제 버튼 위 배지**로 승격 | **A12** |
| ⑥ 분석 저장 | 대화 제목에 **주제 태그** 부착 | **A13** |

### 가져오지 않을 것

- **⑦ 레이어 토글 레일** — 대시보드 본체 기능이라 우리 범위 밖(임베드로 이미 접근 가능).
- **마법사 단계 나누기** — AI가 있는데 단계를 늘리면 후퇴. A9 한 번의 클릭으로 압축한다.
- **챗봇을 구석으로** — 골목상권의 약점이지 강점이 아니다. AI가 주역인 것이 우리 포지셔닝.

## 4-2. 사용자 여정 분석 (Entry → Retention)

골목상권의 "나도 곧 사장" 경로를 끝까지 밟으며 6단계 여정으로 분해하고, 우리 서비스의 단계별 구멍을 진단한다.

> **전제**: 참고한 여정 프레임워크는 커머스형(가격·리뷰·결제)이다. 골목상권도 우리도 **무료 정보 서비스**라 4·5단계는 본질로 치환해서 본다.
> - **Decision** = 가격 비교 → **"이 지역/주제로 정할까"** (비교·근거·**한계 고지**)
> - **Action** = 결제 → **"분석 실행 → 결과물 획득"** (리포트·저장)

### 단계별 대조

| 단계 | 사용자 목표 | 골목상권의 해법 | 우리 현황 | 마찰 | 우리 해결책 |
|---|---|---|---|---|---|
| **1 Entry** | 이게 뭔지 이해 | 헤드라인 "더욱 쉽고 간편해진 상권분석 서비스" + **페르소나 3카드**(`나도 곧 사장`만 노란색 = 추천 경로 지정) + 실물 규모 숫자(점포 624,791개 · 매출 87,575억) + 페이지별 "○○이란?" 모달·튜토리얼 | 제목만. 온보딩 없음. 규모 신호 약함(492개·958.3) | "뭔지 모르겠어" | **A11** AI 첫 인사말로 정의·사용법 · **A12** 기준 배지로 규모·신뢰 신호 |
| **2 Discovery** | 내 조건에 맞는 것 찾기 | 필터가 아니라 **질문으로 시작** — "창업하려는 업종이 있으세요? [아니요, 고민중입니다][네, 있습니다]" → 업종 **대분류 4개만**(전체·외식·서비스·소매, `전체`가 기본 선택) → `확인`. 상단에 선택값 고정 + `처음으로 ↩` | 8개 주제 버튼 = **데이터 축** 기준 | 너무 많은 옵션 / "나한테 뭐가 필요한지 모르겠다" | **A9** 목적 칩 3개 → 주제 자동 선택 + 질문 자동 전송. **골목상권은 3단계 마법사, 우리는 AI로 1클릭 압축** |
| **3 Evaluation** | 이게 괜찮은지 판단 | 선택 업종 기준 **TOP 10 랭킹**("1 송파구 잠실4동 49개 6.52%↑"), 지표 탭 4개로 축 전환, **리스트 순위 = 지도 마커 번호 1:1**, 기준 시점 헤더 고정, "지역 선택에 참고해 보세요"(단정 안 함) | 히트맵·지도·산점도 패널. 시각화는 좋으나 **"그래서 1등이 어디야"에 즉답 없음** | 정보 과다 — 지도를 읽을 줄 알아야 함 | **A10** 주제별 제안 질문으로 랭킹을 AI 답변으로 흡수("교체율 높은 동 TOP 5"). 리스트는 정적이지만 AI는 "왜"까지 설명 |
| **4 Decision** | 최종 확인 | 푸터 고정 고지("**참고 사항**이며… **투자결과에 법적 책임 없음**"), 데이터 업데이트일(2026.08.18), 지표별 `?` 툴팁, 22개 분기 비교 | **우리가 더 낫다** — `insights.md`에 "매출·유동인구 없이 점포 수만 본 분석, 흥망 단정 안 함" / "업소번호 등장·소멸로 추정" 명시 + AI가 "리포트에 없으면 없다고 답한다" 규칙 | 숨은 불확실성 | 유지. 단 **한계 고지를 화면에도** 노출(현재는 AI 답변 안에만) → A12에 포함 |
| **5 Action** | 빠른 완료 | 지역까지 좁히면 **명확한 전환 CTA** — "창업 예정지 상세분석 / 보행권역·반경·다각형으로 상세히 / **[GO]**". 여정 종착점이 **리포트라는 산출물**. 전체 3단계, 각 단계에 복귀 경로 | **종착점이 없음.** 주제 → 답변 → 끝. "그래서 뭘 얻었지?"가 남음 | 산출물 부재 | **A14 (신규)** 주제 리포트 CTA |
| **6 Retention** | 재사용·추천 | 로그인 → `분석리포트 비교담기`에 **저장명** 붙여 저장·비교 | 대화 기록은 있으나 제목이 첫 메시지에서 파생 → `이 주제 핵심만 한 줄로` 같은 제목이 중복 누적 | 잊혀짐 / 식별 불가 | **A13** 대화 제목에 주제 태그 |

### 여정 성숙도 진단

```
        Entry      Discovery    Evaluation    Decision     Action    Retention
골목상권  ●●●        ●●●          ●●●          ●●●         ●●●        ●●●
우리      ●○○        ●○○          ●●○          ●●●         ○○○        ●○○
          ↑A11·A12   ↑A9          ↑A10         (우리 강점)  ↑A14       ↑A13
```

**가장 큰 구멍 2개**
1. **Discovery** — 진입 질문이 "데이터 축"이라 첫 사용자가 막힌다 → **A9**
2. **Action** — 여정에 종착점(산출물)이 없다 → **A14**

**이미 우리가 더 나은 것** — Decision 단계의 한계 고지·근거 제시. 골목상권은 푸터 법적 고지로 처리하지만, 우리는 **AI가 답변마다 근거 수치를 제시하고 없는 건 없다고 말한다.** 이건 지키고 더 드러낸다.

**우선순위**: `A9(Discovery) > A10(Evaluation) > A11·A12(Entry) > A14(Action) > A13(Retention)`

## 6. 단계별 실행 계획

### Phase 1 — 대시보드 통합 (동료평가 제출 후 착수)

핵심 포트폴리오 서사를 완성한다.

- **포함**: A1, A2, A3a, A3b, F3, E1, E5
- **완료 기준**: 라이브 URL에서 대시보드 필터를 바꾸고 "지금 화면 기준으로 서구 음식점 얘기해줘"라고 물으면, AI가 현재 선택된 자치구·업종·기간을 인지하고 답한다. README가 포트폴리오 리더용으로 재구성돼 있다.
- **예상 공수**: 약 M+M+M+L+S+S+M ≈ 8~10일

### Phase 1-b — 사용자 여정 보강 (벤치마킹 반영, Phase 1 직후)

§4-1·§4-2에서 진단한 여정의 두 구멍(**Discovery** 진입 질문 부재, **Action** 종착점 부재)을 메운다.

- **포함**: A9(목적 칩) · A10(주제별 제안 질문) · A11(AI 인사말 온보딩) · A12(기준 배지 + 한계 고지) · A14(주제 리포트 CTA) · A13(대화 제목 주제 태그)
- **완료 기준**: 처음 방문한 사람이 **목적 칩 하나 → 답변 → 리포트**까지 이탈 없이 도달한다. 주제를 바꾸면 제안 질문도 함께 바뀐다.
- **예상 공수**: A9 M + A14 M + 나머지 S ×4 ≈ 3~4일
- **최소선**: **A9 + A10**만 해도 Discovery 구멍이 닫힌다. A14는 그다음 우선.

### Phase 2 — 실무 완성도

- **포함**: C1, C2, C4, C5, C6, D3, A4
- **완료 기준**: CI가 초록이고 테스트가 핵심 경로를 덮는다. 채팅이 스트리밍된다. 데모 데이터를 언제든 복구할 수 있다. 로그로 요청·비용을 추적할 수 있다.
- **예상 공수**: 약 6~8일

### Phase 3 — 심화 (시간 예산 내에서)

- **포함**: B1, B2, B3, C3, C7, E2, E3, E4, F1, F2, (선택 D1·D2·B4·B5)
- **완료 기준**: 실제 상권 데이터가 들어가 요약이 의미를 가진다. 문서(ADR·회고·데모 영상)가 갖춰진다. 접근성·성능 목표 달성.

> **최소 제출 가치선**: Phase 1만 완료해도 포트폴리오로 제출할 가치가 있다. Phase 2·3은 확보 가능한 시간에 따라 취사선택.
