## 1. 배경과 목적

미션 제출본(**v1.0**)은 코디세이 네이토 사전평가를 전 항목 통과했다. 이 문서는 그 결과물을 **채용 포트폴리오 수준**으로 끌어올리기 위해 필요한 작업을 스펙으로 정의한다.

### 서사 전환

| | v1.0 (제출본) | 포트폴리오 목표 |
|---|---|---|
| 한 줄 정의 | 시계열 데이터를 아는 AI 비서 | **대전 상권 대시보드를 보면서 AI와 대화하며 상권을 분석하는 도구** |
| 사용자 행동 | 숫자 몇 개 입력 → 질문 | 지도·차트에서 지역·업종·기간을 고르고 → 그 화면에 대해 질문 |
| 차별점 | 컨텍스트 주입(요약) | 컨텍스트 주입(요약 + 사전 분석 리포트 + **지금 보고 있는 화면 상태**) |

이미 합의된 3단계 계획(1: 현재 제출본 / 2: 중앙 대시보드 임베드 + 우측 채팅 / 3: 대시보드 필터 상태를 채팅 프롬프트에 주입)을 이 문서에서 **실행 가능한 스펙 항목**으로 분해하고, 포트폴리오에서 실무 감각을 보여줄 신뢰성·문서 항목을 더한다.

## 4. 비범위 (Non-goals)

- 대시보드 자체를 프레임워크로 재구현 — 분석 저장소 산출물을 **그대로 임베드**한다. *(결정 ①: iframe 임베드 확정)*
- 실시간 협업, 결제, 네이티브 모바일 앱.
- **인증·멀티유저 전체 (D 그룹)** — 서사를 "개인 상권 분석 도구"로 확정. D1·D2 제외. *(결정 ②)*
- 커스텀 도메인 — Vercel/Render 기본 URL 유지. *(결정 ④)*
- 미션 채점 기준을 넘어서는 "제품화" (SLA, 온콜 등).

## 6. 단계별 실행 계획

### Phase 1 — 대시보드 통합 (동료평가 제출 후 착수)

핵심 포트폴리오 서사를 완성한다.

- **포함**: A1, A2, A3a, A3b, F3, E1, E5
- **완료 기준**: 라이브 URL에서 대시보드 필터를 바꾸고 "지금 화면 기준으로 서구 음식점 얘기해줘"라고 물으면, AI가 현재 선택된 자치구·업종·기간을 인지하고 답한다. README가 포트폴리오 리더용으로 재구성돼 있다.
- **예상 공수**: 약 M+M+M+L+S+S+M ≈ 8~10일

### Phase 2 — 실무 완성도

- **포함**: C1, C2, C4, C5, C6, D3, A4, A5
- **완료 기준**: CI가 초록이고 테스트가 핵심 경로를 덮는다. 채팅이 스트리밍된다. 데모 데이터를 언제든 복구할 수 있다. 로그로 요청·비용을 추적할 수 있다.
- **예상 공수**: 약 6~8일

### Phase 3 — 심화 (시간 예산 내에서)

- **포함**: B1, B2, B3, C3, C7, E2, E3, E4, F1, F2, (선택 D1·D2·B4·B5)
- **완료 기준**: 실제 상권 데이터가 들어가 요약이 의미를 가진다. 문서(ADR·회고·데모 영상)가 갖춰진다. 접근성·성능 목표 달성.

> **최소 제출 가치선**: Phase 1만 완료해도 포트폴리오로 제출할 가치가 있다. Phase 2·3은 확보 가능한 시간에 따라 취사선택.
