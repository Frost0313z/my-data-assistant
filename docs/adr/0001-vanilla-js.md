# ADR 0001 — 프레임워크 없이 바닐라 JS로 만든다

**상태** 유효 · **날짜** 2026-09 (사후 기록)

## 맥락

AI 채팅 + 대시보드 임베드 + 지도를 붙이는 단일 페이지다. 화면은 세 칸(사이드바·분석·채팅)이고 상태라고 부를 만한 것은 *선택한 주제*, *선택한 행정동*, *대화 목록* 정도다.

## 결정

**빌드 단계 없는 순수 HTML/CSS/JS로 만든다.** 유일한 빌드 스크립트는 배포 시 API 주소를 치환하는 20줄짜리 `build.js`다.

## 왜

- 상태가 작다. `window.screenContext` 하나와 DOM 이벤트로 충분했고, 실제로 지도(7지표)·페르소나·스트리밍까지 붙이는 동안에도 상태 관리 도구가 아쉬웠던 적이 없다.
- **정적 호스팅이 공짜가 된다.** Vercel에 그대로 올라가고 빌드 시간이 0이다.
- 리뷰어가 `js/chat.js`를 열면 바로 읽힌다. 번들러 설정을 이해할 필요가 없다.

## 대신 잃은 것

- **컴포넌트 재사용이 없다.** 버튼 생성 코드가 파일마다 조금씩 반복된다.
- **타입 검사가 없다.** 실제로 `--map-change-down` / `--map-change-N` 이름이 어긋나 램프 색 하나가 빈 문자열이 된 적이 있다. 콘솔 경고를 붙여 두지 않았으면 못 잡았다.
- **문법 오류를 잡아 줄 것이 없다.** 그래서 CI에 `node --check`를 넣었다.

## 언제 뒤집나

화면이 하나 더 생기거나(라우팅 필요), 같은 컴포넌트를 세 번째로 복사하게 될 때.
