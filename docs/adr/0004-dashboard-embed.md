# ADR 0004 — 대시보드를 이식하지 않고 임베드한다

**상태** 부분 번복 ([`../decisions.md`](../decisions.md) ⑦) · **날짜** 2026-09 (사후 기록)

## 맥락

이미 만들어 둔 분석 대시보드(`daejeon-commercial-analysis`)가 있다. 지도·히트맵·산점도·막대 8종이 들어 있고 단일 HTML 1.8MB다.

## 결정

**시각화를 다시 만들지 않는다.** 주제 버튼을 누르면 대시보드의 해당 패널만 `?only=` 파라미터로 iframe에 띄운다.

## 왜

- **이중 관리를 피한다.** 분석이 갱신되면 임베드도 같이 갱신된다. 이식했으면 두 곳을 맞춰야 한다.
- 8종을 다시 만들 시간에 이 서비스의 차별점(AI 설명·한계 고지)에 쓰는 것이 낫다.
- 원본으로 넘어가는 링크가 **의도된 이탈**이다 — "AI 설명 → 원본 검증"이 성립해야 브랜드가 완성된다.

## 대신 잃은 것

- **팔레트가 다르다.** 임베드 패널은 다크 테마다. 통일하려면 분석 저장소를 고쳐야 해서 범위 밖으로 뒀고, 대신 "데이터 뷰포트"로 액자화했다.
- 1.8MB를 매번 받는다. 지연 로드로 완화했다.
- 크로스오리진이라 안쪽을 제어할 수 없다.

## 어디서 번복됐나

**공급 밀도 지도만 예외다.** 사용자가 "상권분석에서 중요한 것은 지도"라고 판단해 첫 화면의 주역으로 올렸고, 그러려면 우리 화면 안에서 지표를 바꾸고 행정동을 골라 AI에게 넘겨야 했다. iframe으로는 안 된다.

그래서 MapLibre로 다시 그렸다(A22~A26). 지도 관련 3종을 흡수해 임베드 패널은 8개 → 5개가 됐다. **나머지 5종은 여전히 임베드다** — 시계열 선그래프와 산점도는 이식할 이유가 없다.
