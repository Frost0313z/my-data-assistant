# 벤치마킹 — 서울시 상권분석서비스(골목상권)

> **상위**: [문서 허브](../PORTFOLIO_SPEC.md) · **조사일**: 2026-09-08
> 출처: https://golmok.seoul.go.kr/commercialArea/commercialArea.do
> 성격: 레퍼런스. A9~A13의 도출 근거.

---

## 전제 — 성격이 다르다

같은 도메인(상권 데이터 공개 서비스)의 대표 사례다. **다만 성격이 다르다는 점이 핵심이다.**

- **골목상권** = 데이터를 *보여주는* 서비스. 챗봇은 우상단 아이콘의 보조 도구.
- **우리** = 데이터를 *설명해주는* 서비스. AI가 주역.

그래서 베끼는 게 아니라 **골라 쓴다.**

## 골목상권이 잘하는 것

| # | 패턴 | 관찰 |
|---|---|---|
| ① | **페르소나 기반 진입** | 상단 네비가 `뜨는 상권 / 나는 사장 / 나도 곧 사장`. "무슨 데이터를 볼래?"가 아니라 **"너는 누구냐"**로 나눠 처음 온 사람이 자기 자리를 찾는다 |
| ② | **질문으로 시작하는 마법사** | "나도 곧 사장" 첫 화면이 **"창업하려는 업종이 있으세요?" → [아니요, 고민중입니다] / [네, 있습니다]**. 이후 업종(외식업·서비스업·소매업) → 지역 순으로 좁혀가고 "처음으로"로 되돌아갈 수 있다 |
| ③ | **강제 온보딩** | 페이지마다 "○○이란?" 모달 + `튜토리얼 시작하기` + `다시 보지 않기`. 서비스 정의를 첫 3초에 전달 |
| ④ | **랭킹이 화면의 중심** | 좌측 `순위 TOP 10` — "1위 송파구 잠실4동 441개 7.8%↑". 지도를 못 읽어도 리스트만 보면 답이 나온다. 지도 마커에도 수치를 직접 얹음 |
| ⑤ | **기준 시점 상시 노출** | "2026년 2분기 기준 (전분기)"를 랭킹 바로 위에 고정 → 데이터 신뢰성 방어 |
| ⑥ | **결과를 남긴다** | `분석리포트 비교담기` — 저장명을 붙여 분석을 저장·비교 |
| ⑦ | 레이어 토글 레일 | 우측 아이콘 7개(상권영역·점포이력·주변정보·유동인구 도로별/건물별·인구밀도·지원센터)로 지도 레이어 on/off |

## 우리가 가져올 것 → 스펙 반영

| 벤치마크 | 우리 방식 | 스펙 |
|---|---|---|
| ① 페르소나 진입 · ② 질문 마법사 | 목적 칩 3개 → **주제 자동 선택 + 질문 자동 전송**. 마법사 단계를 AI가 한 번에 압축하는 것이 우리 차별점 | **A9** |
| ④ TOP 10 랭킹 | 리스트를 직접 렌더하지 않고 **주제별 제안 질문**으로 AI가 답하게 ("교체율 높은 동 TOP 5") | **A10** |
| ③ 온보딩 모달 | 모달로 막지 않고 **AI의 첫 인사말**로 (채팅 서비스에 더 자연스러움) | **A11** |
| ⑤ 기준 시점 | 하단 각주 → **주제 버튼 위 배지**로 승격 | **A12** |
| ⑥ 분석 저장 | 대화 제목에 **주제 태그** 부착 | **A13** |

---

## 가져오지 않을 것

- **⑦ 레이어 토글 레일** — 대시보드 본체 기능이라 우리 범위 밖(임베드로 이미 접근 가능).
- **마법사 단계 나누기** — AI가 있는데 단계를 늘리면 후퇴. A9 한 번의 클릭으로 압축한다.
- **챗봇을 구석으로** — 골목상권의 약점이지 강점이 아니다. AI가 주역인 것이 우리 포지셔닝.
