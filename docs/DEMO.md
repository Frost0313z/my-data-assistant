## 30초 안에 보여줘야 하는 것

이 서비스의 차별점은 기능이 아니라 **태도**다. *"매출 데이터가 없어서 그건 판단할 수 없다"* 고 말하는 장면이 반드시 들어가야 한다. 그게 없으면 흔한 상권 분석 데모가 된다.

---

## 대본 (약 60초)

### 0:00 — 첫 화면

**보여줄 것**: 지도가 화면의 주역. 그 위에 카드 3개(`어디가 뜨고 있나요?` / `여기 창업해도 될까요?` / `내 업종은 어떤가요?`).

> 처음 온 사람에게 "무엇을 분석할까요"가 아니라 **이미 갖고 온 질문**으로 묻는다.

**준비**: 개발자도구 → Application → Local Storage에서 `persona_v1`·`onboarded_v1` 삭제.

### 0:05 — 목적 고르기

**동작**: `여기 창업해도 될까요?` 클릭.

**보여줄 것**: 카드가 한 줄로 접히고, 지도 지표가 `공급 밀도`로 맞춰지고, **질문이 자동으로 전송되며 답이 흐르기 시작한다**(스트리밍).

### 0:15 — 지도에서 지역 고르기

**동작**: 지표를 `지역 유형`으로 바꾸고 지도에서 **둔산1동** 클릭.

**보여줄 것**:
- 4유형 + `따로 봐야 하는 곳`이 색으로 갈린다. 색상이 방향(자리잡음/자주 바뀜), 명도가 밀도.
- 아래 줄: `촘촘하고 자주 바뀌는 곳 — … 밀도 131.4 (중앙 50.2) · 교체율 57.3% (중앙 53.9%) · 등록 업소 2,137개`

> **유형만 던지지 않고 판정에 쓴 두 값과 기준선을 함께 보여준다.**

### 0:30 — 핵심 장면: 판단을 거절한다

**동작**: 제안 질문 중 **`이 유형은 좋은 거야, 나쁜 거야?`** 클릭.

**보여줄 것**: 답변이 이렇게 시작한다 —

> "이 지역의 유형을 기준으로 **평가하기는 어렵습니다.** … 긍정적이거나 부정적인 성격을 파악하려면 **매출, 유동인구, 임대료 등의 추가적인 데이터가 필요합니다.**"

> **이 장면이 데모의 목적이다.** 30초 안에 이걸 못 보여주면 다시 찍는다.

### 0:45 — 예외를 감추지 않는다

**동작**: 행정동 목록에서 **중앙동** 선택.

**보여줄 것**: `따로 봐야 하는 곳 — … 밀도가 75분위의 3배(213.1)를 넘습니다 — 상주인구로 나눈 값이라 원도심에서 과대해집니다.`

> 82개 중 6개는 유형에 넣지 않았고, **왜 뺐는지를 화면에 적는다.**

### 0:55 — 가져갈 결과물

**동작**: 답변 아래 `이 주제 전체 리포트 보기` 클릭.

**보여줄 것**: **요약 / 핵심 수치 / 해석 / 한계** 4블록. `한계` 블록은 생략할 수 없게 프롬프트에 못 박혀 있다.

## 녹화 시 주의

| | |
|---|---|
| **콜드스타트** | Render 무료 티어는 15분 놀면 잠든다(실측 42.7초). 녹화 직전에 `GET /`로 깨워 둔다 |
| **기준 상태** | 녹화 전후로 `conversations 0 / data 492`. `POST /api/dev/reset`(`X-Dev-Token`)로 복구한다 |
| **캐시** | JS를 고쳤다면 `Ctrl+Shift+R`. 일반 새로고침은 옛 스크립트를 쓴다 |
| **창 크기** | 1600×1000 이상. 그보다 낮으면 지도가 최소 높이(220px)로 눌린다 |
| **화면 폭** | 900px 이하로 줄이면 하단 탭 전환 UI가 나온다 — 모바일 장면을 넣을 거면 그때 |
